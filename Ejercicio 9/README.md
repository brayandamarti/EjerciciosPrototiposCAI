# Ejercicio 9 – Gestión de Tickets de Soporte Técnico (NetAssist)

Diseño de formularios WinForms (.NET 8). Cada formulario vive en una carpeta con su mismo nombre, sin el sufijo `Form`.

| Actor | Carpeta | Formulario |
|---|---|---|
| Todos | `MenuPrincipal` | `MenuPrincipalForm` |
| Cliente | `RegistrarTicket` | `RegistrarTicketForm` |
| Operador | `DerivarTicket` | `DerivarTicketForm` |
| Técnico | `ResolverTicket` | `ResolverTicketForm` |
| Cliente | `NotificacionCierre` | `NotificacionCierreForm` |
| Jefe de soporte | `EvaluarSoporte` | `EvaluarSoporteForm` |

Abrir `NetAssist.Tickets.sln` con Visual Studio 2022 y ejecutar con F5.
