# Ejercicio 6 – Atención Médica en Clínica (Clínica CAI)

Diseño de formularios WinForms (.NET 8). Cada formulario vive en una carpeta con su mismo nombre, sin el sufijo `Form`.

| Actor | Carpeta | Formulario |
|---|---|---|
| Todos | `MenuPrincipal` | `MenuPrincipalForm` |
| Recepcionista | `AgendarTurno` | `AgendarTurnoForm` |
| Médico | `AtenderPaciente` | `AtenderPacienteForm` |
| Farmacéutico | `EntregarMedicamentos` | `EntregarMedicamentosForm` |
| Cajero | `CobrarConsulta` | `CobrarConsultaForm` |

Abrir `ClinicaCAI.Atencion.sln` con Visual Studio 2022 y ejecutar con F5.
